# Contributing to tpt-mosaic

Thanks for your interest in tpt-mosaic!

## Issues only

This project **does not accept pull requests** at this time. Contributions are welcome in the form of **issues**:

- **Bug reports** — something is broken or behaves unexpectedly.
- **Feature requests** — an idea or improvement you'd like to see.
- **Questions and feedback** — about design, behavior, or documentation.

Pull requests opened without prior agreement will be closed without review.

## Before opening an issue

1. Search [existing issues](https://github.com/tpt-solutions/tpt-mosaic/issues) to avoid duplicates.
2. Use the latest `master` or release if possible.

## Bug reports

Please include:

- A clear description of the problem and the behavior you expected.
- Steps to reproduce, ideally a minimal example.
- Your OS, Rust version (`rustc --version`), and tpt-mosaic version or commit.
- Relevant logs or error output.

## Feature requests

Describe the problem you're trying to solve, not just the solution you have in mind. Context on your use case helps us evaluate it.

## Security vulnerabilities

Do not report security issues in a public issue. Contact the maintainers privately via GitHub's private vulnerability reporting on the repository's Security tab.
